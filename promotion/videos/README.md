# Promo videos

**Kept: the five kinetic films** (`_tools/kinetic.py`, 2026-11-21). One script, five looks (punch, zoom,
fly, scroll, glitch), each vertical 1080×1920 and landscape 1920×1080, 34–41 s, every cut on the beat of
an original track synthesized by `_tools/kmusic.py` (no samples). Release plan and captions: `RELEASE.md`.

```bash
uv run --with numpy --with scipy promotion/videos/_tools/kinetic.py     # all, or ... kinetic.py 01 03
bash promotion/videos/_tools/review_kinetic.sh                          # check + contact sheets → _review/kinetic/
bash promotion/videos/_tools/render_kinetic.sh                          # MP4s → _out/kinetic/
uv run --with numpy --with scipy promotion/videos/_tools/kinetic_gallery.py
```

Copy lives in `content()` and `QUESTIONS`/`TIMELINE` at the top of `kinetic.py`; each look is a class
(camera, word reveal, colours). Generated project folders are git-ignored; rebuild them from the tools.

Earlier rounds, kept for reference: `story.py` (four calmer looks, 67–70 s, `meetup/script.md`) and the
first ten game-centred reels below (`build.py`).

## First round (build.py)

Ten promo ideas for the meet-up, each in two shapes: `vertical/` (1080×1920, Instagram Reels,
Shorts, TikTok) and `landscape/` (1920×1080, the website, slides, X). Every project is a
[HyperFrames](https://hyperframes.heygen.com) folder: `index.html` + `compositions/*.html`,
plain HTML and GSAP, editable by hand or in the HyperFrames desktop app.

| # | Name | What it shows | Music |
|---|---|---|---|
| 01 | spot-the-ai | Human or AI? three works from the wall, guessed and turned over | Joplin |
| 02 | into-the-wall | The wall flips; the camera dives into a poem that becomes a printed card | Bach |
| 03 | kinetic-type | Kinetic type on a dark ground, flashes of real works | Original beat |
| 04 | wall-to-game | 02's opening into 01's game | Joplin |
| 05 | every-medium-game | The game with a poem, a film and an AI poem | Satie |
| 06 | four-questions | The four questions of the meet-up | Chopin |
| 07 | who-and-what | What the meet-up is, and the nine organizers | Bach |
| 08 | ninety-minutes | The 90-minute schedule, then two rounds of the game | Joplin |
| 09 | any-medium | One real work per medium, then one round | Original beat |
| 10 | teaser-loop | A short teaser: the wall, then where to submit | Satie |

Every scene ends on the same invitation and end card (vertical: "Link in bio"; landscape:
"Submit your work"). No voice.

## Change and rebuild

The projects are generated by `_tools/build.py`: copy, works, order and music are in its
`VERSIONS` list, each scene is one function (`s_rounds`, `s_wall`, `s_card`, …) that lays itself
out for either shape. Edit there and run

```bash
python3 promotion/videos/_tools/build.py          # all, or e.g. ... build.py 03 07
bash promotion/videos/_tools/review.sh            # hyperframes check + contact sheets → _review/
bash promotion/videos/_tools/render_all.sh        # MP4s → _out/
```

A re-run overwrites the generated `index.html` and `compositions/`; hand edits there are lost,
so either edit `build.py` or stop using it for that project. One project by hand:
`cd vertical/01-spot-the-ai && npx hyperframes preview` (or `npx hyperframes open`).
